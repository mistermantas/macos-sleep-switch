# Execution contract

Continue through all milestones without pausing for a routine review. `plans.md` is authoritative.

- Make small, reviewable changes and add tests where the code has a test seam.
- Run the relevant validation after each milestone; fix failures before continuing.
- Preserve privacy: no credential, API key, or secret is committed.
- Update `plans.md` and `documentation.md` after each completed milestone.
- Do not claim an App Store upload without checking Apple’s build state.

Completion means the product behavior is implemented and validated, the source is pushed to `main`, and the iOS artifact is valid in App Store Connect. macOS delivery may only be marked blocked when a current Apple certificate/provisioning failure is retained as evidence.
